# Axeptio CMP — Google Tag Manager Template

This repository hosts the Axeptio CMP tag template for the [GTM Community Template Gallery](https://tagmanager.google.com/gallery).

For setup instructions, configuration details, and Consent Mode v2 documentation, see:

👉 **[Axeptio Help Center — Google Consent Mode v2](https://support.axeptio.eu/articles/274002)**

For any questions, contact [support@axeptio.eu](mailto:support@axeptio.eu).
